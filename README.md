# ✿ A Little Room of My Own

An interactive pixel-art bedroom where my portfolio comes to life. Explore my world through a little character, cozy surroundings, and a growing collection of things I'm passionate about.

🎮 **[Play the live demo](https://addieactuallystudies-source.github.io/aditi-room-learning/)**

## ✨ Features

* 🏡 A cozy, pixel-art bedroom environment
* 🎮 Character movement using the arrow keys
* 👟 Directional sprites and walking animations
* 🌷 Separate idle poses for each direction
* 💻 A personal portfolio world in progress

## 🛠️ Built With

* HTML — page structure
* CSS — layout and styling
* JavaScript — movement, keyboard controls, and animation
* GitHub Pages — deployment

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/addieactuallystudies-source/aditi-room-learning.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
